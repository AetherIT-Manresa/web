# AetherIT · Web corporativa

Web estàtica amb HTML5, CSS3 i JavaScript.

```
web-empresa/
├── index.html
├── css/style.css
├── js/script.js
└── images/logo-icon.svg
```

## Provar en local (VSCode)
1. Obre la carpeta `web-empresa` a VSCode.
2. Instal·la l'extensió **Live Server** i fes clic dret a `index.html` → *Open with Live Server*.

## Desplegar a GitHub Pages
1. Puja el contingut al repositori de l'organització AetherIT (`git add .`, `git commit`, `git push`).
2. Al repositori: Settings → Pages → Deploy from a branch → `main` / `(root)`.
